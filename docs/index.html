Ninguna ruta de negocio de esta API tiene middleware de autenticación. El filtrado por perfil (user_email → perfiles_id) es una regla de presentación, no un control de acceso. Antes de probar, revisa que el server seleccionado no sea producción: hay endpoints que facturan (/certificado/save-url, /electro-cardiograma/save, /carga-masiva-ecg, /estadisticas/pago-mensual) y uno que borra facturación (/estadisticas/delete-pago-mensual).
Este visor cubre el contrato operación por operación. Para la vista de conjunto —cómo se encadenan los flujos, qué clase llama a cuál y cómo se relacionan las tablas— están los diagramas: arquitectura, flujos end-to-end, clases y modelo de datos.
